
# ☕ Core Java

> 📚 **Core Java** is the foundation of the Java programming language. It provides the fundamental concepts, syntax, and features required to build robust, scalable, and platform-independent applications.

---

## 🎯 What is Core Java?

Core Java refers to the **fundamental features of Java** that every Java developer should master before learning advanced frameworks like **Spring Boot**, **Hibernate**, or **Microservices**.

It includes concepts such as:

- 📦 JDK, JRE & JVM
- 🏗️ JVM Architecture
- 📂 Class Loader
- 💾 Memory Management
- 🧩 OOP Principles
- 🔤 Strings
- ⚠️ Exception Handling
- 🧵 Multithreading
- 📚 Collections Framework
- ⚡ Java 8 Features
- 🔄 Stream API
- 🗑️ Garbage Collection

---

## 🚀 Why Learn Core Java?

Mastering Core Java helps you:

- ✅ Build a strong programming foundation.
- ✅ Understand how Java works internally.
- ✅ Write clean, efficient, and maintainable code.
- ✅ Crack Java Backend Developer interviews.
- ✅ Learn advanced frameworks like Spring Boot with ease.
